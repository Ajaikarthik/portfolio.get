Forensic analysis

This project focuses on building a secure digital forensic system that ensures the integrity and authenticity of data using blockchain technology and cryptographic techniques. In digital forensics, it is very important to prove that evidence has not been altered. This system addresses that problem by combining hashing, secure key generation, and blockchain structure.

The project uses the SHA-256 algorithm to generate unique hash values for data. These hashes act as digital fingerprints. Even a small change in the data will produce a completely different hash, making tampering easy to detect.
